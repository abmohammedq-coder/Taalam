# تشغيل الفصول عبر Daily — الخطة المجانية التجريبية

يتيح Daily تضمين غرفة الفيديو داخل المنصة دون تشغيل خادم Jitsi/Jibri خاص. الخطة المجانية الحالية تتضمن **10,000 دقيقة مشارك شهريًا**، وليست 10,000 دقيقة اجتماع. تحسب الدقائق: عدد المشاركين × مدة الاتصال. بعد انتهاء الحصة المجانية، قد تُطبق أسعار الاستخدام الإضافي إذا أُضيفت وسيلة دفع؛ لا تفترض أن الخدمة مجانية بلا حدود.

## إعداد الحساب

1. أنشئ حسابًا مجانيًا في https://www.daily.co/ .
2. افتح لوحة Daily ثم قسم Developers وأنشئ API Key.
3. انسخ نطاق الحساب الذي ينتهي عادةً بـ `.daily.co`، مثل `your-school.daily.co`.
4. لا تضع API Key في المتصفح أو داخل ملفات HTML/JS، ولا ترسله في المحادثات. يجب حفظه كمتغير سري في الخادم فقط.

## إعداد Railway أو بيئة الخادم

أضف المتغيرات التالية في إعدادات Variables:

```env
MEETING_PROVIDER=daily
DAILY_DOMAIN=your-school.daily.co
DAILY_API_KEY=ضع_مفتاح_Daily_هنا
```

ثم أعد نشر التطبيق. لا تغيّر `JITSI_DOMAIN`؛ يبقى متاحًا عند اختيار مزود Jitsi.

## سلوك التكامل

- ينشئ الخادم غرفة Daily خاصة لكل حصة عند أول انضمام، ثم يحفظ رابطها في سجل الحصة ويعيد استخدامه.
- يصدر الخادم رمز دخول قصير الصلاحية لكل مشارك؛ لا يُكشف مفتاح API للمتصفح.
- المعلم/مدير المدرسة يحصل على صلاحية مالك الغرفة، والطالب ينضم دون صلاحية مالك ويبدأ الميكروفون مكتومًا.
- تُضمّن واجهة Daily Prebuilt داخل صفحة التعليم الإلكتروني، مع رابط احتياطي لفتح الغرفة.
- لا يُفعّل التسجيل السحابي أو التسجيل التلقائي في هذا الإعداد؛ التسجيل السحابي خدمة مدفوعة منفصلة. يمكن الاستمرار في رفع ملف التسجيل بعد الحصة عبر ميزة المنصة الحالية.
- عند غياب إعداد Daily أو اختيار `MEETING_PROVIDER=jitsi` يستمر مسار Jitsi السابق كما هو.

## حساب استهلاك تقريبي

حصة فيها معلم و10 طلاب لمدة 40 دقيقة = 11 × 40 = 440 دقيقة مشارك. عشرة آلاف دقيقة تكفي نظريًا لنحو 22 حصة من هذا الحجم في الشهر، قبل احتساب التجارب أو إعادة الدخول أو المشاركين الإضافيين.

## الحدود والتحذيرات

- هذه خدمة مستضافة لدى طرف ثالث، وليست خادمًا تملكه المدرسة.
- الخطة المجانية محدودة بالدقائق الشهرية؛ راقب الاستخدام في لوحة Daily.
- لا تحفظ تسجيلات أو بيانات طلاب حساسة في الخدمة دون مراجعة سياسة الخصوصية والاحتفاظ بالبيانات وموافقة الجهة التعليمية وأولياء الأمور حيث يلزم.
- لم يتم اختبار الاتصال الفعلي بحساب Daily تابع للمالك؛ يلزم إدخال مفتاح حقيقي ثم اختبار اجتماع بين حساب معلم وطالب على جهازين وشبكتين.
