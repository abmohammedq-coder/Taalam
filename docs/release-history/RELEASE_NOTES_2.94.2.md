# الإصدار 2.94.2

## صلاحيات المعلمين على مستوى الحساب
- إضافة واجهة لمدير المدرسة لتحديد صلاحيات كل معلم نشط على حدة.
- إضافة API لقراءة وحفظ صلاحيات المعلم داخل نطاق المدرسة نفسها.
- تطبيق القيود على الخادم لعرض لوحة المعلم والدرجات والملاحظات وإضافة/تعديل/حذف الدرجات.
- تظل جميع العمليات مقيدة بإسنادات الصفوف والمواد الحالية للمعلم، ولا تمنح هذه الصلاحيات وصولًا إداريًا عامًا.
- تسجيل تغييرات صلاحيات المعلم في سجل التدقيق.

## حدود الإصدار
- لا يتضمن هذا الإصدار بعد دور مسؤول شؤون الطلاب المستقل.
- لم تُضف بعد لوحة تحكم فردية للطالب أو ولي الأمر؛ تظل صلاحياتهما محصورة في بياناتهما المرتبطة والمصرح بها.
- لم تُنفذ ميزة العمل بالنيابة عن المستخدم أو الفصول الافتراضية في هذا الإصدار.
