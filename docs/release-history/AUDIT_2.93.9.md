# تدقيق الإصدار 2.93.9

## نطاق التدقيق
تغيير واجهة إعداد المقررات من مربعات اختيار إلى قوائم منسدلة، مع خيار «أخرى» لإضافة مادة جديدة وإضافتها إلى مواد المدرسة ثم إسنادها للصف الحالي.

## الحماية والتوافق
- لم يتغير مخطط بيانات المدرسة: تبقى `subjects` قائمة مواد المدرسة و`gradeSubjects` خريطة مقررات لكل صف.
- بقيت قواعد التحقق على الخادم التي تمنع رصد مادة غير مقررة للصف.
- لا يؤدي حذف مادة من مقررات صف إلى حذف درجاتها التاريخية.
- لا يؤدي إدخال مادة جديدة إلى استبدال مواد الصفوف الأخرى.
- إزالة مادة من صف لا تحذفها من القائمة العامة للمدرسة.

## الاختبارات
- اجتاز فحص JavaScript المضمن في `school-admin.html` باستخدام `node --check` بعد استخراج النصوص البرمجية.
- اجتاز `scripts/workflow-ui-check.js` بنتيجة 31/31.
- اجتازت بقية مجموعات الاختبار عند تشغيلها منفردة: voice 6/6، learn 13/13، pdf smoke 118/118، HTTP 17/17، learn API 26/26، features 95/95، book jobs 44/44، simulations 58/58، advanced 7/7، UI 55/55، academics 97/97.
- أمر `npm test` الموحد تجاوز مهلة التنفيذ في بيئة الفحص بعد إنهاء مجموعات مبكرة؛ لذلك شُغلت المجموعات منفردة للتحقق منها. لا أدّعي أن الأمر الموحد اكتمل في جلسة واحدة.
