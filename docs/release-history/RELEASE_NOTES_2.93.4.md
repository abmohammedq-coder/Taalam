# الإصدار 2.93.4 — توحيد لوحة إدارة المدرسة

## التغييرات
- إزالة قائمة التنقل النصية الجانبية المكررة، والاعتماد على مربعات أقسام إدارة المدرسة في لوحة البداية.
- إضافة دليل الإدارة إلى مربعات الأقسام.
- دمج الوصول إلى إنشاء المحتوى داخل قسم المحتوى والمنشورات، مع زر لإنشاء منشور جديد والعودة إلى المنشورات.
- إضافة زر عودة موحد إلى أقسام إدارة المدرسة داخل الصفحات الفرعية.
- إضافة بحث فوري عن سجل الطالب داخل طلبات ربط البريد، مع قصر النتائج على الصف والشعبة في الطلب.
- عدم اختيار سجل الطالب تلقائيًا؛ يجب على مدير المدرسة اختياره صراحةً.
- تفعيل زر اعتماد الربط فقط عند اختيار سجل يطابق الاسم بعد تطبيع الكتابة العربية، مع استمرار التحقق النهائي على الخادم من المدرسة والصف والشعبة والاسم وعدم وجود ربط سابق.
- تحديث إصدارات التخزين المؤقت لتجنب عرض الواجهة القديمة بعد التحديث.

## ما لم يتغير
- لم تتغير قاعدة البيانات أو مخطط التخزين.
- لم تتغير واجهات API أو صلاحياتها.
- لم تحذف وظائف الرسوم أو إعداداتها أو التقارير أو الحضور أو الشهادات أو العام الدراسي.
