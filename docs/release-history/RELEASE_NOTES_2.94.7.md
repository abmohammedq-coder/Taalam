# الإصدار 2.94.7

## كشوف آخر الدرجات — عرض مصفوفي تراكمي
- استبدال عرض بطاقات/قوائم الدرجات داخل صف الطالب بكشف مصفوفي شبيه بجداول Excel.
- في إدارة المدرسة: صف واحد لكل طالب، وعمود مستقل لكل تركيبة مادة + فصل دراسي + محصلة/اختبار.
- في صفحة المعلم: صف واحد لكل طالب، وعمود مستقل لكل تركيبة فصل دراسي + محصلة/اختبار ضمن المادة والصف المسندين للمعلم.
- تظهر الدرجة داخل تقاطع الطالب مع نوع التقييم، مع الدرجة العظمى وتاريخ الرصد وأزرار التعديل والحذف وفق الصلاحية.
- تمييز أحدث درجة مضافة على مستوى الكشف باللون الأخضر، وتظهر الخلايا التي لا تحتوي درجة بشرطة بدل إنشاء صفوف إضافية.
- إذا تكرر سجل للطالب في نفس عمود التقييم، تعرض الخلية أحدث سجل فقط لمنع تكرار الطالب أو إظهار درجات متضاربة في الخلية. عناوين الاختبارات المخصصة والأعوام الدراسية المختلفة تبقى أعمدة مستقلة حتى لا تندمج تقييمات مختلفة.
- رفع حد سجلات آخر الدرجات إلى 20,000 سجل في إدارتي المدرسة والمعلم، لدعم المدارس الكبيرة التي تضم ألف طالب أو أكثر.
- تحديث الكشف مباشرة بعد الحفظ أو التعديل أو الحذف.
- دعم التمرير الأفقي وتثبيت عمود اسم الطالب لتسهيل مراجعة الكشوف الكبيرة وعلى الهاتف.

## الاختبارات
- تحديث اختبارات الواجهة للتحقق من بنية الكشف المصفوفي في صفحتي الإدارة والمعلم.
- اجتازت اختبارات الواجهة وسير العمل والاختبارات الأكاديمية وفحص صياغة JavaScript المضمنة.
