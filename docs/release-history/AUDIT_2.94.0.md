# تدقيق الإصدار 2.94.0

## النطاق الذي تغير
- `server.js`: قاموس صلاحيات، تصنيف الصلاحية المطلوبة بحسب مسار الطلب وطريقته، تطبيق القرار داخل `requireSchoolAdmin`، وواجهتا API لقراءة وضبط صلاحيات الوكيل.
- `public/school-admin.html`: إضافة محرر صلاحيات الوكيل ضمن إعدادات المدرسة، يظهر لمدير المدرسة فقط.
- `public/sw.js`, `public/admin/sw.js`, `public/school-admin/sw.js`: تحديث مخابئ التطبيقات الثلاثة إلى 2.94.0.
- `package.json`: تحديث الإصدار وإضافة اختبار سياسة الصلاحيات إلى بداية مجموعة الاختبارات.
- تحديث فحوصات الإصدار التي كانت تتوقع 2.93.9 حتى لا تعتبر رقم المخبأ القديم صحيحًا.

## مراجعة الأمان والسلوك
- المدير principal له صلاحيات كاملة داخل مدرسته فقط.
- جلسة الوكيل تعرض هوية الجلسة ولوحة القراءة الأساسية، لكن عمليات التعديل تتطلب تفويضًا مؤقتًا ساريًا وصلاحية محددة.
- الصلاحيات الممنوحة للوكيل تُنسخ عند بدء التفويض. انتهاء التفويض يمنع عمليات التعديل حتى لو كانت الصلاحية مضبوطة.
- لا تسمح واجهة إعداد الصلاحيات بمنح مفتاح تجاوز عام للمسارات غير المصنفة.
- التحقق ما زال مرتبطًا بهوية المدرسة من الجلسة؛ لا يوجد مسار يمنح مدير المدرسة وصولًا إلى مدرسة أخرى.
- لم يتم بعد تنفيذ صلاحيات الأدوار الوظيفية للمعلمين وشؤون الطلاب، أو التحكم الفردي الكامل بكل حساب، أو العمل بالنيابة عن مستخدم.
