# الإصدار 2.95.1

## تجهيز اتصال خادم الفصول الخاص
- إضافة `JITSI_SELF_HOSTED=1` لمنع الرجوع الصامت إلى `meet.jit.si` عند اعتماد خادم خاص.
- عند غياب `JITSI_DOMAIN` في وضع الخادم الخاص، يعيد التطبيق خطأ إعداد واضحًا بدل إنشاء رابط عام.
- الإبقاء على السلوك التجريبي السابق عند `JITSI_SELF_HOSTED=0`.
- إضافة دليل تشغيل Jitsi/Jibri ومتطلبات النشر والحدود الحالية في `deploy/jitsi/README.md`.

## ما لم يُنفذ في هذا الإصدار
- لم يتم إنشاء أو تشغيل VPS.
- لم يتم تثبيت Jitsi أو Jibri فعليًا.
- لا يوجد JWT أو تسجيل تلقائي أو استيراد تلقائي لتسجيلات Jibri.
- السبورة لم تتحول بعد إلى تعاون لحظي.
