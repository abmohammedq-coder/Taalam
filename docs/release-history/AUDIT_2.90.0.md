# تدقيق الإصدار 2.90.0 — تنظيم واجهات الأدوار

## التغيير الأساسي
- كانت بوابة `/school` تعرض منشورات المدرسة وأدوات المعلم والجدول والحضور والملاحظات والتسليمات في بطاقة طويلة واحدة.
- أصبحت الآن واجهة مهام حسب الدور، وتُعرض الأقسام كأزرار. الضغط على الزر يخفي شبكة الأقسام ويفتح مساحة مستقلة للقسم، مع زر رجوع.
- المعلم: منشورات المدرسة، نشر محتوى للطلاب، رصد درجات المواد، الجدول المدرسي، ملاحظات الطلاب.
- الطالب: منشورات المدرسة، الجدول، سجل الحضور، واجباته وتسليماته، ويظهر تسجيل حضور الفصل فقط عند تعيينه مندوبًا.
- لم تتغير معرفات النماذج أو عناصر DOM الوظيفية، ولا واجهات API أو قواعد الصلاحيات والحفظ.

## بقية الواجهات التي راجعتها
- إدارة المدرسة: قائمة أقسام جانبية، وكل قسم يفتح تبويبًا واحدًا؛ عناصر إدخال الطلاب والنتائج والنماذج الثقيلة تفتح في نوافذ مستقلة.
- إدارة المنصة: أزرار أقسام رئيسية، وبطاقات مهام تفتح واجهات مستقلة.
- تطبيق الطالب: شبكة أزرار وورقة كاملة الشاشة للأقسام.
- بوابة ولي الأمر: تبويبات منفصلة لعرض الأبناء وربط ابن جديد.
- بوابة المعلم `/teacher`: تسجيل الدخول ثم توجيه معلم المدرسة إلى مساحة المدرسة؛ حسابات المعلمين المستقلة تبقى في تبويب إعداد الدرس ومسوداتي.
